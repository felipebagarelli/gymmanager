# Gym Manager

Sistema de gerenciamento de academia desenvolvido com Java e Spring Boot.

## Tecnologias

- Java 25
- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- Maven
- Lombok

## Funcionalidades

- Cadastro de membros
- Listagem de membros
- Busca de membro por ID

## Em desenvolvimento

- Atualização de membros
- Exclusão de membros
- Cadastro de treinos
- Associação de treinos aos membros
- Validações
- Tratamento de exceções
- Testes unitários
- Spring Security
